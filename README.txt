# Nowgong Polytechnic website starter

## Files
- `index.html` — homepage structure
- `style.css` — responsive layout and styling
- `script.js` — dropdown menu, mobile menu and font-size controls
- `assets/` — place your institute images here

## Add your real photographs and logo
1. Copy a good, wide photograph of the Nowgong Polytechnic campus into `assets/`.
2. Name it exactly `campus.jpg`.
3. In `index.html`, replace the text-only NP logo mark with your approved institute logo if available. The logo mark is currently a simple text placeholder.
4. The hero image is loaded by `style.css` from `assets/campus.jpg`. The welcome photo area is currently a placeholder panel; it can be changed to an `<img>` element when you have a second photograph.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the root of your GitHub repository.
2. In Settings → Pages, choose Deploy from a branch, `main`, and `/(root)`.
3. Open the published GitHub Pages URL.

## Embed in Google Sites
Insert → Embed → By URL, then paste the GitHub Pages URL. Resize the embed to the maximum width available in the Google Sites section. The embed will fill its iframe, but cannot extend outside the iframe or beyond Google Sites' content area.

## Important
- Replace placeholder section links (`#...`) with actual pages or URLs.
- Confirm official institute wording, contact details, department names, admission links and regulatory references before publishing.
- Do not place confidential student information, passwords or API keys in this public static website.
- GitHub Pages is static hosting; it does not run PHP or provide a database.
